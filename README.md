# Cardiovascular AI Portfolio

Machine learning for cardiac abnormality detection and hemodynamic prediction.

## Projects
1. **ECG Classification (PTB-XL)**: Multi-class classifier to detect cardiac conditions from 12-lead ECG signals.
2. **Physics-Informed Hemodynamic Prediction (MIMIC-III)**: Hybrid ML system predicting blood pressure/cardiac output using cardiovascular fluid dynamics principles.
3. **Transfer Learning (Optional)**: Cross-modal and multi-task learning demonstration.

pip install -r requirements.txt

## Structure
- `data/`: Datasets (not tracked by git)
- `notebooks/`: Jupyter notebooks for exploration and prototyping
- `src/`: Source code for data loading, modeling, and training
- `configs/`: Configuration files
- `results/`: Output figures, models, and logs
